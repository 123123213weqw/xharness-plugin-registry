# XHarness GitHub

Ten original GitHub CLI workflow Skills: setup, commit, pr, issue, release, workflow-run, secret, repo, gist, codespace.

Requires the locally installed GitHub CLI (`gh`) and the user’s own authentication. No embedded credentials, executable hooks or MCP process. Installation does not enable the plugin.

These instructions are authored for XHarness; this package does not copy the previous third-party CDN bundle. GitHub CLI itself is not bundled. See https://cli.github.com/manual/.
