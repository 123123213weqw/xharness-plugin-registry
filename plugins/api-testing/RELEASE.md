# api-testing 0.1.0-beta.1

**Opt-in beta / 用户自选测试版。**

Read OpenAPI contracts, probe HTTP endpoints and build evidence-bound API regressions. Beta; Python 3 and project-specific validators are separate prerequisites.

Authored workflow and bounded helper tests are not real-model or live-service acceptance. PostgreSQL/MySQL credentials, Docker daemon, project test clients and production mutations are not bundled or universally validated. Existing user data and software are not migrated.
