# browser 0.1.0-beta.1

**Opt-in beta / 用户自选测试版。** Installation does not enable the plugin or install dependencies. Existing user data is not migrated.

Requires an actual documented browser automation backend supplied by the host; this package does not install Chromium, CDP, MCP or an embedded browser. Without that backend, it supplies an explicitly unexecuted action plan. Twelve finite controlled webpage tasks passed; arbitrary websites/platforms/authenticated browsing are not certified.

No full-source parity, statistical improvement or full-platform acceptance is claimed. Keep user edits and authentication separate from plugin code.
